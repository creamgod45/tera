# Tera Template Studio 介紹影片：場景書與導演劇本

- 片長：約 2 分 10 秒（可剪成 60 秒短版，見最後一節）
- 對象：用 Rust（Rocket、Zola 等）寫網站、模板用 Tera 的開發者
- 一句話主旨：**在 RustRover 裡寫 Tera 模板，IDE 知道變數從哪來、寫錯當場告訴你。**
- 語言：旁白繁體中文，畫面字幕中英對照（英文版可直接用同一份場景書）
- 畫面規格：1920×1080、30 fps；IDE 用淺色與 Darcula 各錄一份，成片用深色為主

## 一、導演說明

**調性**：安靜、俐落、像在身邊看同事操作，不誇張。每個功能只給 8 到 15 秒，講「痛點，再示範，再結果」。

**節奏原則**
1. 每一幕先出現問題（紅線、誤報、找不到），再出現解法。觀眾要先痛，才會覺得有用。
2. 游標移動要慢、要有停頓；重點處放大（Zoom 到 150%），不要讓觀眾找字。
3. 字幕一次只放一行，不超過 14 個中文字。
4. 不放背景音樂的歌詞；用低調的電子樂，旁白出現時音量降 12 dB。

**示範專案**：用倉庫裡的 `examples/review-poc`（Rocket + Tera 2 的審核系統）。它有元件、推導式、版面繼承與 Rust 端的 context，一個專案就能拍完全片。拍攝前先重新打包並安裝最新的 `tera-1.3.0.zip`，並確認要拍的每個功能在你的 IDE 裡實際看起來正常（我沒有在 IDE 裡驗過畫面外觀，包含 hover 文字與衝突提示）。

## 三、導演劇本（旁白全文，連續念的版本）

> （安靜的電子樂，音量低）

**[1]** Tera 模板寫久了，你一定遇過：變數拼錯了，要等到執行才知道。

**[2]** Tera Template Studio，專為 RustRover 寫的 Tera 模板外掛。

**[3]** 它讀你的 Rust 程式碼，知道模板拿到哪些變數、什麼型別。拼錯的欄位，當場標出來；停在變數上，還能看到它從哪裡來。

**[4]** Tera 2 的推導式很抽象。停在關鍵字上，直接告訴你它在做什麼、迴圈的對象是什麼型別、變數只在括號內有效。

**[5]** 元件有好幾個同名的？Cmd 加點擊，每個定義都附上那一行內容和檔案位置，不用再猜是哪一個。

**[6]** extends 鏈上的 block，一鍵跳到父層、找出所有覆寫；改名的時候，全部同步。

**[7]** 直接印出清單或 map，通常不是你要的。Alt 加 Enter，一鍵改成迴圈，或是 join。

**[8]** 渲染出錯，點錯誤，直接回到模板那一行。從 Rust 的字串，也能一鍵開啟對應的模板。

**[9]** 還在用 Tera 1？它同時支援 Tera 1 和 Tera 2，也能一鍵遷移。

**[10]** Tera Template Studio。現在，就在 JetBrains Marketplace。

（全文約 330 字，以每分鐘 160 到 180 字念，約 1 分 55 秒到 2 分 05 秒，加上轉場剛好 2 分 10 秒。）

## 四、拍攝清單與前置準備

**環境**
- RustRover 最新版，裝好最新的 `tera-1.3.0.zip`，**只裝這一個**，原版 Tera 先移除，否則會衝突。
- 字級調到 18 到 20 pt，隱藏左側專案樹以外的面板；關掉通知；用乾淨的 Rocket 專案視窗。
- 錄影用 macOS 的螢幕錄製或 OBS；游標放大並顯示點擊圈。

**示範資料（每一幕對應）**
- 幕 3：在 `stats.html.tera` 複製一份草稿檔，故意拼錯 `stats.totl`。
- 幕 4：`examples/review-poc/templates/pages/stats.html.tera` 第 7 到 10 行。
- 幕 5：同一檔的第 13 到 16 行有多個 `ui.*`，是現成的「同一行兩個呼叫」素材。
- 幕 7：另存一份模板，放 `{{ categories }}`（清單）。
- 幕 8：故意讓一個模板在執行時出錯，錄 Run 視窗；或貼一段實際的 Tera 錯誤輸出。
- 幕 9：準備一份 Tera 1 風格的模板（`| map(attribute="…")`）。

**每幕要錄兩次**：一次慢速（供剪輯放慢與 Zoom），一次正常速度。

## 五、剪輯與後製

- 每幕之間 0.3 秒溶接，幕 1 到 2 之間用黑場。
- 字幕用同一字型，白字加半透明深色底，位置在下三分之一。
- 重點操作加淡色高亮框（不要動畫太花）。
- 完成後輸出：2 分 10 秒完整版、60 秒短版、以及每幕獨立的 10 秒 GIF（放 README 與 Marketplace 頁面）。

2. Marketplace 上架是否通過審核；沒通過的話改用從磁碟安裝的結尾。
3. 是否要英文版旁白或只做字幕。
4. 有無要露臉或配音的人選；沒有的話可用文字轉語音，但語氣要自然。
